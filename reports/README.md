# Report guide

- `eda_summary.json`: raw split shape, missingness, duplicates and word lengths.
- `class_distribution.csv`: class support in cleaned training, validation and official test.
- `split_manifest.json`: all labels in integer-ID order, source hashes and split counts.
- `tokenization.json`: measured untruncated training lengths and fraction exceeding the limit.
- `training_history.json`: epoch loss and validation macro F1; no test-based selection.
- `training_run.json`: training configuration, hardware/software and selected epoch.
- `baseline_metrics.json`, `transformer_metrics.json`: accuracy, macro/weighted precision, recall and F1, measured cost.
- `*_classification_report.json`: per-intent performance and support.
- `*_predictions.csv`: held-out row-order true and predicted IDs; join locally with processed test data for text review.
- `*_confusion_matrix.csv`: full 77-by-77 named matrices; figures use manifest IDs for readability.
- `MODEL_COMPARISON.md`: generated comparison, weakest classes, common confusions and timing caveats.
- `example_predictions.json`: actual saved-model outputs, including an out-of-domain example.

Figures and metrics are generated by the implementation. Original customer text is not copied into prediction CSVs. Public benchmark examples are displayed in the EDA notebook. Saved models and raw/processed datasets remain local and ignored by Git.
